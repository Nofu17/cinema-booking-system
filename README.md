# 🎬 Cinema Booking System

A full-stack cinema ticket booking web application built with Django and MVC architecture, allowing users to browse movies, select showtimes, book tickets, and manage reservations.

## 📱 About the Project

Cinema Booking System is a web application that streamlines the movie ticket booking experience — from browsing currently showing movies to selecting showtimes and confirming bookings, all through a clean and responsive interface.

## ✨ Key Features

- 🎥 **Movie Catalog** — Browse currently showing movies with genre, rating, and duration
- 🎟️ **Showtime Management** — View and select available showtimes, halls, and seat availability
- 📝 **Booking System** — Book tickets with full name and seat count, with instant confirmation
- 🛠️ **CRUD Operations** — Add, edit, and delete movies and showtimes
- 📊 **Admin Dashboard** — Overview of total movies, confirmed bookings, and currently showing films
- 🗑️ **Safe Delete** — Confirmation dialogs before deleting movies or showtimes

## 🛠️ Built With

- **Python** — Programming language
- **Django** — Web framework
- **SQLite** — Database
- **Django Templates** — Server-side rendering
- **HTML & CSS** — Frontend structure and styling

## 🎓 Context

Developed as part of coursework applying MVC architecture principles using the Django framework, focusing on database relationships, CRUD operations, and responsive UI design.
